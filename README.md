职介招聘系统，后端基于 ThinkPHP 开源框架开发，前端为微信小程序，主打**赏金内推招聘模式**，专为职业介绍机构、劳务中介搭建，区别于传统招聘平台，依托推荐赏金激励机制撬动求职者、中介、工人共同推荐人才，解决蓝领招工难、候选人获取成本高的痛点。

系统分为求职者小程序端、企业后台、平台总后台。求职者在小程序完善简历，浏览岗位、投递简历，成功推荐好友入职并满足约定在岗周期，即可领取推荐赏金；企业方发布招聘岗位，设置招聘赏金金额、结算条件、结算周期，可查看投递简历、沟通候选人，跟踪面试、入职、离职状态。平台总后台基于 ThinkPHP 开发，负责企业资质审核、岗位审核、赏金规则配置、赏金结算管理、会员套餐、数据统计、资金流水记录，统一管控全平台订单与佣金。

底层采用 ThinkPHP 经典 MVC 架构，代码开源，结构清晰，方便二次开发。数据库核心表包含企业信息、简历、岗位、投递记录、赏金订单、结算记录。赏金流程可自定义配置：设置入职满指定天数方可结算赏金，支持赏金冻结、审核、发放、驳回机制，有效规避推荐后短期离职带来的资金损失。同时内置消息模板推送，投递成功、面试邀约、赏金待审核、赏金到账等状态实时通知用户。

部署需要服务器、域名、数据库，配置 PHP 运行环境，导入数据库，配置微信小程序、微信支付、短信接口。后台配置岗位分类、赏金模板，测试简历投递、推荐分享、赏金结算流程，提交微信审核即可上线。可按需扩展直播带岗、简历下载、子中介分销等功能。

方案适合劳务中介、人力资源服务商搭建蓝领招聘平台，依靠赏金内推模式实现裂变招工。使用开源源码务必阅读开源协议，商用获取授权。上线需遵守招聘平台监管规则，做好求职者个人信息加密保护，规范赏金结算机制，防范劳务纠纷与资金风险。
